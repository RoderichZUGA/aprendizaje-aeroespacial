# Circuitos eléctricos

## Propósito

Construir una comprensión física y matemática de los circuitos eléctricos.

## Temas

- Análisis de mallas
- Equivalente de Thévenin
- Transformadores
- Transistores
- Sistemas eléctricos de aeronaves
- Baterías y BMS

## Lo que ya comprendo

- El sentido de una corriente de malla puede elegirse arbitrariamente.
- Una corriente negativa indica que el sentido real es contrario al supuesto.
- La relación de transformación compara las espiras y los voltajes del primario y el secundario.

## Preguntas abiertas

- ¿Cómo interpretar físicamente el voltaje de Thévenin?
- ¿Cómo se construyen las ecuaciones de un circuito desde su topología?
- ¿Cómo se relaciona un BMS con la arquitectura eléctrica completa?
